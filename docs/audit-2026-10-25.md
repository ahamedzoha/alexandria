## Code — P1

- [x] ✔ **Library truncated at 200 items** — `APIClient.swift:104` sends `limit=200`, never pages. Search, grouping, filters, Continue all wrong for bigger libraries. Fix: page until `results.count < limit` (or `limit=0`).
- [x] ✔ **Stale offline pending entry regresses server progress** — failed PATCH queues t=100; next successful PATCH (t=115) then `flushPending` re-sends t=100 (`AppState.swift:578-581`, `DownloadStore.swift:228`). Queued "mark finished" can re-finish a restarted episode. Fix: clear `pending[key]` on successful PATCH; guard concurrent flushes. Add a test first.
- [x] ✔ **Downloaded items resume from local position, ignoring newer server progress** — `Playback.swift:30-36`. Cross-device listening gets overwritten. Fix: start from the newer of local vs `progressByItem` (by lastUpdate), still play local files.
- [x] **Stale async responses after server/library switch** — `loadProgress`, `loadItems`, `loadEpisodes`, `refreshRecentEpisodes` (`AppState.swift` ~442-748) don't check server/library unchanged; slower response wins; `isLoading` cleared by whichever finishes first. Fix: capture `(activeServerID, libraryID)` before await, discard on mismatch; cancel superseded load tasks.

## Code — P2

- [x] ✔ **Sleep timer runs fast above 1×** — periodic observer ticks on item timeline but counted as 0.5s wall (`PlayerEngine.swift:218`). Fix: `step: 0.5 / rate`. Also `.endOfChapter` with `end == 0` fires immediately (`:112`).
- [x] ✔ **Finished threshold 0.99 fraction** — 18 min left on a 30h book marks it finished (`AppState.swift:554,578`). Fix: remaining < ~30s.
- [x] ✔ **`play()`/`toggle()` with nothing loaded set `isPlaying = true`** (`PlayerEngine.swift:272`). Play after natural end does nothing (no seek to start); `didFireFinished` never reset after seek/replay.
- [x] **Cancellation surfaces as "Could not reach server"** — `APIClient.swift:56-63` wraps `CancellationError`/`URLError.cancelled`. Closing a podcast sheet early pops a bogus error.
- [x] **Silent download failures; zero-track "downloaded" record can't be retried** — `DownloadStore.swift:131-135, 189-192`. Cover HTTP status unchecked (`:161-167`).
- [x] **AVPlayer failures unobserved** — no `AVPlayerItem.status` / failed-to-play-to-end observation; 401/404/LAN drop = silence.
- [x] **Logout/remove server leaves audio playing; pending queue global across servers** (404 retried every 45s forever). `removeServer` resets view even for a non-active server. (`AppState.swift:273-289`, `DownloadStore.swift:228`)
- [x] **Every 401 → "Wrong username or password", no re-auth path** (`APIClient.swift:70`). Expired/revoked token leaves user stuck.
- [x] **Download URLs carry `?token=` for every file**, not only `/hls/` (`DownloadStore.swift:259-275`) — token lands in proxy logs. Use Bearer header via `URLRequest`.
- [x] **`loadProgress` replaces whole map** — undoes optimistic marks (`AppState.swift:452`). Merge by `lastUpdate` like `loadEpisodes`.
- [x] **CoverCache**: no invalidation (changed covers stale forever), unbounded parallel fetches, 3×60s timeouts when unreachable; `PaletteStore` negative-caches transient failures (`ArtworkPalette.swift:104-110`).
- [x] **Play sessions never closed / no `/api/session/{id}/sync`** — ABS listening stats miss Alexandria; fixed `deviceId`, `clientVersion = "0.1"`.
- [x] **`package.sh` silently falls back to `0.0.0` / build `1`** if `-showBuildSettings` fails (`:35-48`) — breaks Sparkle offers silently. Add `exit 1` guards; first `sign_update` found in DerivedData wins (`:97-103`).
